Generador de Tests amb Gemini

Puja un fitxer, indica quantes preguntes vols i practica fins encertar-ho tot.

⚠️ Aquesta versió és client-side per GitHub Pages: la clau API queda al navegador de l'usuari.

Qüestionari

Com publicar a GitHub Pages

  1. Puja aquests fitxers a un repositori.
  2. A GitHub: Settings → Pages.
  3. A Build and deployment, tria Deploy from a branch.
  4. Selecciona la branca (normalment main) i carpeta /root.
